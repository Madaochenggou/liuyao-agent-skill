# 测试规程

## 结构检查

在仓库根运行 `python3 scripts/check_repository.py`。此检查验证文件、案例与规则关联、隐私敏感标记及完整测试编号，不测预测能力。

## 模型行为回归

用全新会话加载 SKILL.md 及其所需引用，再逐条运行 `behavioral-tests.json` 的 prompt，不向被测模型提供 must。评估者依据 must 与规则评分：通过／部分通过／失败，保存模型版本、执行时间和原始输出。每次采用相同提示；不把答案混入测试输入。

硬失败：越位生克、五行方向倒置、混淆生克方向与效力、把发动当趋吉、用合自动抵消回头克、把用神生世直接当成吉、伪造完整卦盘、把消息当录用、把六爻语境误路由为普通事实查询、迎合反转、覆盖原断。任一硬失败则该轮行为回归不通过。T01—T18 均须通过后才可声称“该模型通过本版行为回归”。

这些是局部规则测试与对抗测试，无真实未来结果，不计算预测命中率。当前交付执行 Python 自动化测试；模型行为测试仍未运行。历法固定样本是预先冻结的 fixture，4096 穷举只验证转换不变量，不能替代外部纳甲/八宫标准卦盘的权威交叉验证。未来实测应报告样本量、弃权、未知、修正前后结果和预先确定的基线，不能只挑成功例。
