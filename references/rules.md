# 规则与边界 v0.1

本文件是项目采用的分析约定，不是所有六爻流派的共识。规则编号用于审计，不是计算预测概率的权重。

| 编号 | 规则 | 操作与常见误用 |
|---|---|---|
| R01 | 先校盘 | 初爻在下，逐行标动静；月与日分栏。不能把戌日说成戌月。六行缺失时只作局部审查。 |
| R02 | 取用依问题 | 求职可围绕岗位官鬼，同时考察世应；若问书面通知，父母可能为主。兄弟不能自动等同强竞争者；同类多现须说明选择依据。 |
| R03 | 先成败后应期 | 先判断目标事件是否有成立依据。凶断可以给复核窗口，不能转而默认某日必成。 |
| R04 | 动爻有效性 | 分开写本爻基础力量、动爻对他爻作用、本位变化、生克方向及其限制。发动表示变化，不直接等于成功或联系。暗动须另证日冲及旺衰条件。 |
| R05 | 近事重日辰 | 先按问事期限定义近远；数日事件先审日辰，数月事件更重月令及阶段。该优先级来自本项目经验，不能解释成近事忽略月破、远事忽略日辰。 |
| R06 | 旬空低独立权重 | 旬空与旺衰、动静、生扶、冲实及出空条件合看。“旺不为空、动不为空”只作提醒，不能无条件宣布空亡不存在或出空必应。 |
| R07 | 变爻本位 | 本框架不让变爻越位直接生克冲合其他本卦爻。动爻本身的跨爻作用另论。其他流派须明确声明，不能中途混用。 |
| R08 | 生克方向 | 变生本才是回头生；变克本为回头克；本生变为化泄。午火→未土是火生土，可同时论午未合，不能写成回头生。 |
| R09 | 合克并见 | 卯木克戌土与卯戌合可以共存；不可见合便抹掉克，也不能忽略合。以日月、有效性、问事关系说明取舍；若口径改变结论，降低信心或暂不能判断。 |
| R10 | 无效克不等于被克者弱 | 若假设巳火空破不能有效回克申金，只能推得该项制约减弱；申金本身强弱另证，不能据此说竞争者弱。反向口径须独立列出。 |
| R11 | 过程结果分开 | 拖延和失败需要不同证据；有消息不等于推进，有推进不等于录用。六神、卦名、归魂游魂只作辅助，不能独断吉凶或诊断现实心理。 |
| R12 | 主断与可证伪 | 一个明确主断，允许资料不足时暂不能判断；记录最强反证及失败条件，不能用“有机会但有阻碍”包容一切结果。 |
| R13 | 冻结预测 | 预测与修正分版本保存；到期无目标事件即按预定口径评估，不能无限延长期限。资料无法观测则记未知，不能当命中。 |
| R14 | 生克方向与效力分离 | 先判断五行关系方向，再判断日月、旺衰、动静、空破等是否使其有效；关系存在不等于作用足够。 |
| R15 | 发动不等于趋吉 | 动爻表示变化或过程，不预设变化方向。 |
| R16 | 合不自动解克 | 动化六合与回头克可以同时成立；不能因为有合就自动取消回头克。 |
| R17 | 用神生世须审自身 | 用神生世只是方向支持；用神自身衰弱受制时，不得直接认定成事吉象。 |
| R18 | 分层评分 | 成败、过程、应期分别定义成功标准和评分；次要预测命中不能掩盖成败主断失败。 |
| R19 | 双维评价 | 基础卦理推导正确性与现实预测结果正确性独立评价；一项通过不代表另一项通过。 |

## 推荐推理表

每个关键爻列：盘面事实 → 本次取象 → 日月基础 → 动变方向 → 有效性限制 → 对目标事件的支持／反对 → 不确定性。事实、传统规则、项目经验和现实假设分开。

不使用未经校准的机械加分表。一次预测错误只能产生待检验假设，不能证明或推翻整套框架；理法检查通过也不证明现实预测有效。
