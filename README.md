# 六爻断事 Agent Skill

一个中文、可审计的纳甲六爻分析 Skill：取用神 → 校验日月动变 → 先成败后应期 → 明确主断 → 事前登记 → 事后验证。

它解决的是模型的推导纪律与可验证表达，不承诺预测准确率。当前为 v0.1 研究版本，规则未经过实证效能验证；“近事重日辰”“旬空低独立权重”等是项目约定，经典出处尚未逐条校勘。

## 安装与使用

将整个 `liuyao-agent-skill` 文件夹放入支持 Agent Skills 的客户端技能目录。Codex 常用路径为 `~/.codex/skills/liuyao-agent-skill/`；安装后按客户端要求刷新技能。其他客户端以其说明为准。本项目不依赖专有插件或网络服务；安装仅需复制本仓库文件。

示例请求：

> 使用 $liuyao-agent-skill，判断我提供的完整卦盘所问事件。先定义成功与截止时间，核对动静与生克，给一个主断，再给条件应期；缺信息请明确指出。请保存事前判断，后续复盘不覆盖原断。

输入应包括具体问题、观察期限、起卦时间与时区、月建日辰旬空、从初到上的完整六爻、世应、动静及本位变爻。不会自动排盘或保证历法换算；盘面不全时可以审查局部错误。

## 文件

- [SKILL.md](SKILL.md)：Agent 入口。
- [规则](references/rules.md)：13 条规则、适用条件和反例。
- [记录模板](references/prediction-record.md)：事前登记及复盘标准。

- [行为测试](tests/README.md)：可在任意模型上手动或批量运行。
- `scripts/check_repository.py`：本地结构、案例及测试关联检查，不执行断卦。

运行 `python3 scripts/check_repository.py` 检查交付结构。行为评估另按测试规程执行；结构检查通过不代表模型行为已通过。
